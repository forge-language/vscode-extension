# Forge LSP 0.2.0

Adds guided language-server setup, start/restart commands and a dedicated output channel. Syntax remains available in untrusted workspaces; tools start only after workspace trust is granted. Compiler/server binaries are installed separately.

Install the VSIX through **Extensions: Install from VSIX…**, then run **Forge: Set Up Language Server**. See the README for native and TypeScript options and troubleshooting.
